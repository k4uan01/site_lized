# Lized

Site estático responsivo recriado a partir do mockup fornecido.

## Visualizar

Abra `dist/index.html` no navegador, ou execute `node server.cjs` nesta pasta e acesse http://127.0.0.1:4389.

## Arquivos

- `dist/index.html`: estrutura e conteúdo.
- `dist/style.css`: layout e adaptação para celulares.
- `dist/app.js`: navegação, projetos, dúvidas e solicitação de orçamento.
- `dist/assets/`: imagens fornecidas. A composição utiliza recortes visuais via CSS da referência para preservar a arte original.

WhatsApp: +55 (45) 9933-7045. E-mail: lizedsystem@gmail.com. Instagram: [@lized_oficial](https://instagram.com/lized_oficial). As solicitações abrem uma mensagem para revisão e envio pelo visitante.

As prévias dos projetos são imagens estáticas de 1536 × 1024, sem logos nos cards nem ação de clique. Os arquivos e prompts de edição estão documentados em `PROJECT-IMAGES.md`. Depoimentos e indicadores reproduzem o conteúdo do mockup.

## Hospedagem

A pasta `dist` pode ser servida por qualquer hospedagem estática. Não há dependências de compilação. A fonte DM Sans é carregada do Google Fonts, com alternativa local Arial.

O registro inicial no Sites foi criado e salvo em `.openai/hosting.json`, mas a publicação não foi concluída porque o script `site-workflow.mjs` do plugin deixou de estar disponível. Reutilize o mesmo identificador ao retomar a publicação; não crie outro site.
